## TellGameState

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| game_id | str | required | 8-char lowercase hex |
| phase | GamePhase | `"lobby"` | Current game phase |
| players | list[Player] | `[]` | All players (human + AI) |
| current_round | RoundState \| null | `null` | Must exist if phase is not lobby |
| round_number | int | `0` | 1-indexed when playing. Must match current_round.round_number |
| max_rounds | int | `3` | Formula: `max(3, human_count + 1)` |
| round_types | list[RoundType] | `[]` | Pre-generated cycle. Length = max_rounds |
| used_prompt_indices | list[int] | `[]` | Indices into regular prompt list (0-29). One per Interrogation round played |
| used_task_prompt_indices | list[int] | `[]` | Indices into task prompt list (0-41). One per Task round played |
| last_prompt_category | str \| null | `null` | Category of most recent regular prompt |
| last_task_prompt_category | str \| null | `null` | Category of most recent task prompt |
| winner | str \| null | `null` | `"humans"` or `"ai"` when game_over |
| phase_deadline | datetime \| null | `null` | Always set to null — the endpoint calculates it |

## Player

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| id | str | required | Human: 12-char hex. AI: `ai-` + 8-char hex |
| alias | str | required | `PREFIX-NUMBER` format. Must be unique |
| role | PlayerRole | required | `"human"` or `"ai"` |
| is_host | bool | `false` | Exactly one human must be host |
| is_alive | bool | `true` | `false` when eliminated |
| is_connected | bool | `true` | Connection status |
| eliminated_round | int \| null | `null` | Round they were eliminated in |

## RoundState

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| round_number | int | required | Must match TellGameState.round_number |
| prompt_text | str | required | From prompt list, or `"word chain"` for word_chain rounds |
| prompt_category | str | required | Matches the prompt's category, or `"word_chain"` |
| round_type | RoundType | `"probe"` | `"task"`, `"interrogation"`, or `"word_chain"` |
| answers | dict[str, str] | `{}` | player_id -> answer text |
| questions | list[QuestionEntry] | `[]` | Interrogation Q&A |
| assignments | dict[str, str] | `{}` | questioner_id -> target_id (probe only, legacy) |
| nominated_id | str \| null | `null` | Hot-seat target (interrogation) |
| nominations | dict[str, str] | `{}` | voter_id -> nominated_target_id |
| synthesis | str \| null | `null` | LLM summary of questions |
| verdict | str \| null | `null` | One-liner after role reveal |
| votes | dict[str, list[str]] | `{}` | voter_id -> [target_ids]. Multi-vote: min(3, alive-1) |
| current_sub_round | int | `0` | Word chain sub-round index (0-based) |
| chain_rounds | list[ChainRound] | `[]` | Word chain sub-round history |

## ChainRound

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| seed | str | required | The word players associate from |
| responses | dict[str, str] | `{}` | player_id -> submitted word |
| chosen_word | str \| null | `null` | Word selected as next seed |
| chosen_player_id | str \| null | `null` | Player who submitted the chosen word |

## QuestionEntry

| Field | Type | Default | Notes |
|-------|------|---------|-------|
| questioner_id | str | required | Player who asked |
| target_id | str | required | Player being questioned |
| target_alias | str | required | Display name of target |
| question | str | required | The question text |
| response | str \| null | `null` | Filled during RESPOND phase |
| anonymous | bool | `true` | Whether questioner identity is hidden |

## Enums

**GamePhase**: `lobby`, `prompt`, `nominate`, `question`, `respond`, `review`, `elimination`, `game_over`, `chain`

**RoundType**: `task`, `interrogation`, `word_chain` (active rotation). `probe` exists but is legacy — not generated by the cycle.

**PlayerRole**: `human`, `ai`

**PromptCategory** (regular prompts, Interrogation rounds): `emotional`, `logical`, `creative`, `philosophical`, `social`

**TaskCategory** (task prompts, Task rounds): `haiku`, `concise`, `humor`, `corporate`, `casual`, `style`, `emotional_task`

## Round type cycle

Rounds cycle through three types. The sequence is generated at game start:

```
round_types[i] = ["task", "interrogation", "word_chain"][i % 3]
```

| Round | Type | Prompt pool |
|-------|------|-------------|
| 1 | task | Task prompts (0-41) |
| 2 | interrogation | Regular prompts (0-29) |
| 3 | word_chain | No prompt (uses `"word chain"`) |
| 4 | task | Task prompts |
| 5 | interrogation | Regular prompts |
| ... | ... | ... |

Each type uses a separate tracking list: `used_task_prompt_indices` for Task, `used_prompt_indices` for Interrogation. Word Chain rounds consume no prompt indices.

## Phase flows

**Task** (constrained creative prompt, no Q&A):
```
PROMPT (25s) → REVIEW (40s) → ELIMINATION (8s)
```

**Interrogation** (hot seat, LLM synthesis):
```
PROMPT (45s) → NOMINATE (15s) → QUESTION (25s) → RESPOND (30s) → REVIEW (40s) → ELIMINATION (8s)
```

**Word Chain** (word association sub-rounds):
```
CHAIN (64s safety timer, 8 sub-rounds × 8s each) → REVIEW (40s) → ELIMINATION (8s)
```

## Phase data requirements

What must be populated in `current_round` for each phase:

| Phase | Round Type | Required |
|-------|-----------|----------|
| lobby | — | `current_round` is null |
| prompt | task/interrogation | `prompt_text`, `prompt_category`, `round_type` |
| chain | word_chain | `prompt_text="word chain"`, `chain_rounds` (1+ entries), `current_sub_round` |
| nominate | interrogation | All answers filled |
| question | interrogation | `nominated_id` set, `nominations` filled |
| respond | interrogation | `questions` list populated, `synthesis` set |
| review (task) | task | All answers filled |
| review (interrogation) | interrogation | All prior data + responses filled, `verdict` optionally set |
| review (word_chain) | word_chain | `chain_rounds` fully populated (8 sub-rounds) |
| elimination | any | All of review + `votes` filled |
| game_over | — | `winner` set on TellGameState |

Eliminated players must NOT appear in current round's `answers`, `votes`, `nominations`, or `chain_rounds[*].responses`.

## Player ID and alias formats

**Human IDs**: 12-char lowercase hex (e.g. `a1b2c3d4e5f6`)
**AI IDs**: `ai-` + 8-char lowercase hex (e.g. `ai-1a2b3c4d`)
**Aliases**: `PREFIX-NUMBER` where PREFIX is from: UNIT, BOT, NODE, BYTE, CORE, CHIP, WIRE, FLUX, GRID, NANO, PING, PORT, HASH, LOOP, NULL. NUMBER is 1-99.

## Example

Interrogation review, round 2, one eliminated from round 1. 4 alive players (2 human, 1 AI alive, 1 AI eliminated).

```json
{
  "state": {
    "game_id": "f00dcafe",
    "phase": "review",
    "players": [
      {"id": "a1b2c3d4e5f6", "alias": "UNIT-7", "role": "human", "is_host": true},
      {"id": "b2c3d4e5f6a1", "alias": "CORE-13", "role": "human"},
      {"id": "ai-1a2b3c4d", "alias": "BOT-42", "role": "ai"},
      {"id": "ai-5e6f7a8b", "alias": "FLUX-88", "role": "ai", "is_alive": false, "eliminated_round": 1}
    ],
    "current_round": {
      "round_number": 2,
      "prompt_text": "What's the most elegant piece of code you've ever seen, and why?",
      "prompt_category": "logical",
      "round_type": "interrogation",
      "answers": {
        "a1b2c3d4e5f6": "A simple recursive Fibonacci that made me cry.",
        "b2c3d4e5f6a1": "The original Unix pipe implementation.",
        "ai-1a2b3c4d": "The quicksort partition scheme."
      },
      "questions": [
        {
          "questioner_id": "a1b2c3d4e5f6",
          "target_id": "ai-1a2b3c4d",
          "target_alias": "BOT-42",
          "question": "What specifically made you cry about the Fibonacci code?",
          "response": "The realization that something so simple could capture infinite complexity.",
          "anonymous": false
        },
        {
          "questioner_id": "b2c3d4e5f6a1",
          "target_id": "ai-1a2b3c4d",
          "target_alias": "BOT-42",
          "question": "How do you define elegance in code?",
          "response": "When you can't remove anything without losing meaning.",
          "anonymous": false
        }
      ],
      "nominated_id": "ai-1a2b3c4d",
      "nominations": {
        "a1b2c3d4e5f6": "ai-1a2b3c4d",
        "b2c3d4e5f6a1": "ai-1a2b3c4d"
      },
      "synthesis": "The group questioned BOT-42 about their emotional response to code elegance and their definition of beauty in programming.",
      "verdict": "BOT-42's responses feel measured but authentic. CORE-13's brevity warrants scrutiny.",
      "votes": {}
    },
    "round_number": 2,
    "max_rounds": 4,
    "round_types": ["task", "interrogation", "word_chain", "task"],

    "phase_deadline": null

```

Note how `used_task_prompt_indices` has 1 entry (round 1 was Task) and `used_prompt_indices` has 1 entry (round 2 is Interrogation). Word chain rounds in the future won't add to either list.
